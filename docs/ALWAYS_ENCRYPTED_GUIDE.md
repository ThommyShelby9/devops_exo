# Guide Always Encrypted pour MedSecure

## 📋 Objectif
Chiffrer les colonnes sensibles (données patients) conformément aux exigences HDS.

## 🔐 Colonnes à chiffrer

### Données Patients (Article 9 RGPD)
- **Nom / Prénom** : Déterministe (pour recherche)
- **Numéro de sécurité sociale** : Déterministe
- **Date de naissance** : Randomisé
- **Adresse** : Randomisé
- **Diagnostic** : Randomisé
- **Prescriptions** : Randomisé

## 🛠️ Configuration

### 1. Créer les clés dans Azure Key Vault

```sql
-- Column Master Key (CMK) stockée dans Azure Key Vault
CREATE COLUMN MASTER KEY [CMK_MedSecure]
WITH (
    KEY_STORE_PROVIDER_NAME = 'AZURE_KEY_VAULT',
    KEY_PATH = 'https://<your-keyvault>.vault.azure.net/keys/CMK-MedSecure'
);

-- Column Encryption Key (CEK)
CREATE COLUMN ENCRYPTION KEY [CEK_MedSecure]
WITH VALUES (
    COLUMN_MASTER_KEY = [CMK_MedSecure],
    ALGORITHM = 'RSA_OAEP',
    ENCRYPTED_VALUE = 0x... -- Generated by Azure Key Vault
);
```

### 2. Configuration EF Core (.NET 8)

**appsettings.json**
```json
{
  "ConnectionStrings": {
    "CatalogConnection": "Server=...;Database=...;Column Encryption Setting=Enabled;"
  }
}
```

**Entity Configuration**
```csharp
public class Patient : BaseEntity
{
    [Required]
    [ColumnEncryption(encryptionType: ColumnEncryptionType.Deterministic,
                      encryptionKeyName: "CEK_MedSecure")]
    public string FirstName { get; set; }

    [Required]
    [ColumnEncryption(encryptionType: ColumnEncryptionType.Deterministic,
                      encryptionKeyName: "CEK_MedSecure")]
    public string LastName { get; set; }

    [Required]
    [ColumnEncryption(encryptionType: ColumnEncryptionType.Deterministic,
                      encryptionKeyName: "CEK_MedSecure")]
    public string SocialSecurityNumber { get; set; }

    [ColumnEncryption(encryptionType: ColumnEncryptionType.Randomized,
                      encryptionKeyName: "CEK_MedSecure")]
    public DateTime DateOfBirth { get; set; }

    [ColumnEncryption(encryptionType: ColumnEncryptionType.Randomized,
                      encryptionKeyName: "CEK_MedSecure")]
    public string Address { get; set; }
}

public class MedicalRecord : BaseEntity
{
    [ColumnEncryption(encryptionType: ColumnEncryptionType.Randomized,
                      encryptionKeyName: "CEK_MedSecure")]
    public string Diagnosis { get; set; }

    [ColumnEncryption(encryptionType: ColumnEncryptionType.Randomized,
                      encryptionKeyName: "CEK_MedSecure")]
    public string Prescription { get; set; }
}
```

### 3. Migration EF Core

```bash
# Créer une migration
dotnet ef migrations add AddAlwaysEncrypted

# Appliquer la migration
dotnet ef database update
```

### 4. Configuration DbContext

```csharp
public class CatalogContext : DbContext
{
    public CatalogContext(DbContextOptions<CatalogContext> options) : base(options)
    {
    }

    protected override void OnConfiguring(DbContextOptionsBuilder optionsBuilder)
    {
        // Always Encrypted requires Azure.Identity for Key Vault access
        var credential = new DefaultAzureCredential();
        var sqlConnection = new SqlConnection(connectionString);
        sqlConnection.AccessToken = credential.GetToken(
            new TokenRequestContext(new[] { "https://database.windows.net/.default" })
        ).Token;

        optionsBuilder.UseSqlServer(sqlConnection);
    }

    public DbSet<Patient> Patients { get; set; }
    public DbSet<MedicalRecord> MedicalRecords { get; set; }
}
```

## 🔍 Différence Déterministe vs Randomisé

| Type | Usage | Exemple |
|------|-------|---------|
| **Déterministe** | Permet recherche, tri, jointure | Nom, Prénom, N° Sécu |
| **Randomisé** | Sécurité maximale, pas de recherche | Diagnostic, Adresse |

## ✅ Validation

```csharp
// Test unitaire pour vérifier le chiffrement
[Fact]
public async Task Patient_SensitiveData_ShouldBeEncrypted()
{
    var patient = new Patient
    {
        FirstName = "Jean",
        LastName = "Dupont",
        SocialSecurityNumber = "1234567890123"
    };

    await _context.Patients.AddAsync(patient);
    await _context.SaveChangesAsync();

    // Vérifier que les données sont chiffrées en base
    var rawQuery = "SELECT FirstName FROM Patients WHERE Id = @id";
    var encryptedData = await _context.Database
        .ExecuteSqlRawAsync(rawQuery, patient.Id);

    // Les données doivent être chiffrées (non lisibles)
    Assert.NotEqual("Jean", encryptedData);
}
```
